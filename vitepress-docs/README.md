# 仓库说明与维护指引

YUNA KnowledgeBase 面向燕山大学师生，由燕山大学大学生网络信息协会维护，记录校园生活与学习中常见问题的解决方法。

## 浏览文档

- [文档首页](/)：查看推荐文章与常用入口。
- [校园服务](/campus-index)与[技术资源](/tech-index)：按主题查找指南。
- [标签索引](/tags)与[最近更新](/recent)：浏览相关内容和修订记录，也可使用站内搜索。

## 使用与纠错

校园政策、套餐、办事流程和系统页面可能变化，以学校当期通知及本人适用的正式文件为准。免费额度、软件版本和学生权益请核对官方页面；核验日期只代表当时的状态。海外服务还需确认地区、账号、支付和条款限制。

- 缺少内容、发现错误或内容过时，可[提交反馈](/wanted)。
- 提交后在[确认页](/wanted-done)保存查询码，通过[反馈执行状态](/wanted-status)查看进度。

## 参与维护

提交 Pull Request 前请阅读[贡献指南](/CONTRIBUTING)与[内容术语与维护规范](/CONTEXT)，也可联系 <admin@yuna.team>。

安装、开发、构建与部署说明统一见 [GitHub 仓库 README](https://github.com/yuna2017/knowledgeBase-new#readme)。维护者可通过[反馈审计](/wanted-audit)处理反馈，访问需要口令。
