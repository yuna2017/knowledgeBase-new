## B 站 UP 主推荐（同上，均萌新向）

- **GeekHour**（uid 102438649）：好。
- **黑马程序员**（uid 37974444）：卖课的，别买。只推荐黑马的 Java，别的大多拉胯，预制商班，课味严重。
- **丑萌气质狗**（uid 90189489）：C# 萌新教学做的还行，就是讲的太细太碎。
- **降星驰**（uid 108753930）：人好，群也好，建议都很真心实用。
- **M_Studio**（uid 370283072）：中文区最经典的 Unity 入门教程作者之一，买他的课别在 b 站，去 Unity 课堂那里，否则附赠的资料不全，b 站可以当试看试学体验一下。
- **Silverjay 银鸟工作室**（uid 28471795）：极好的游戏开发基础教学入门，涵盖面不算窄。
