# 从入学到就业的中登焚诀：开启你的计算机科学与游戏开发之旅

## 1.计算机学习通识
### 写在前面（电子扫盲部分）：
- 浏览器用Edge、Google Chrome、Firefox，别用**360浏览器和各种乱七八糟的浏览器！！**
- 浏览器的很多插件都很好用，比如油猴，需要时请自行搜索了解
- 电脑没有应用商城，想下什么去浏览器搜，然后在官网或别的用户给的下载渠道（例如网盘）里下载安装，学会自己躲开钓鱼网站和假链接假官网
- 电脑要分盘分区，做好文件夹分类，否则后面用着必乱必炸
- 安装东西别安装在默认C盘
- 桌面和任务栏要干净
- 解压软件用7-Zip（也叫Bandizip）、卸载东西的软件用Geek
- 平时的防护软件用火绒就够，真中毒了再请360出山
- 转换格式有格式工厂这个软件，一般够用
- 其他零零碎碎的知识点基本全靠经验堆出来，或者可以麻烦一下关系好的学长学姐问一下，比如收到了奇怪的半段链接，其实是需要自己加网盘前缀或解密，win11系统怎么改ui和菜单变成win10，右键文件的菜单里乱七八糟的东西太多怎么去注册表删除，打战地卡了输入法怎么解决等
- 温馨提示：百度贴吧查询技术问题一般都挺好用的，搜索格式是“问题关键字 + 百度贴吧”，浏览器搜索一般默认空格一下等于“#+标签”

### 1.1	学计算机无从下手？ 计算机的学习，粗略切，可分四块： 
- 计算机基础（408四大件，即**数据结构与算法、操作系统、计算机组成原理、计算机网络**）
- 语言
- 专业领域知识
- 数学（常用线代/离散）

通常，前两项的基础为项三的前提。语言是项目实践的工具。计算机基础四门是软硬件技术的根基，具体侧重依方向而定。

学习语言与基础可互为起点，最后自然会融会贯通的。

专业领域（如游戏）需学习其特有知识（如引擎），虽然依赖四大件和语言，但不掌握独有内容则无法胜任该领域工作。

### 1.2 获得学习路线/学习指引的主要来源：
-他人分享（博客/网站/图文、知乎/b站等平台的文章/视频等）
-JD（即职位描述/招聘需求，优先参考大企业官网校招/社招JD）
-刷面试，再根据面试复盘（偏进阶向）

### 1.3	获得知识的主要来源：
- 视频课（b站或YouTube等国内外各个平台）
- 项目实践（最重要的途径），配合问AI/搜索引擎等，最好是有人带
- 刷题（一般用来练算法/八股/面经）
- 啃书（想进阶不得不走的一步）

### 1.4	刷题：
**力扣 / 牛客**

### 1.5	东西好多好乱，0基础的我该做什么？
1. 准备好上网魔法工具（强烈建议必备，不会的可以问一下关系好的学长学姐），确保全渠道畅通；注册好Github账号（可选）；安装git（可选）；至少注册一个主流国外大模型账号，没注册也得确保能用，最好是GPT（OpenAI）（强烈建议必备）
2. 收集好各处的信息资源，制定好短期学习计划，随后计算机基础or语言二选一入门（有心仪方向也可定制学习路线，无也没事，通用基础基本每个方向都要学）
3. 入门的方式我推荐刷视频课，边学边做小项目练手，不会地方的善用AI/搜索引擎/查书
4. 等到至少学完一门语言基础，并且掌握入门程度的数据结构与算法后，开始刷题，同步开始学习一些常用工具（如git等），当然这个过程中也别忘了持续学习数学
5. 等常用的工具学会了，并且至少刷了几套课，做过点玩具项目后，这时候基本就得确定要做的方向了
6. 根据选择的就业方向，有侧重地继续深造四门基础课中的某几门，及每门基础课内侧重深入哪些部分，深造至少一门语言，多熟悉几门语言，让你的基础和语言不会在HR考八股的时候拖后腿。同时也去根据jd的要求，通过单干/合作的方式做能放上简历的优质项目，并练好八股面经
7. 语言和基础能过笔+面，且有至少1-2个，不说优质，但起码能拿得出手的项目后，就可以尝试投实习了，这时候一般是大二下（优质竞赛奖项，个人博客等给简历竞争力增色的内容，以及熟悉git协同开发等常有的jd要求，包括其它一些软提升，均是多多益善，具体根据你的能力和方向来）

>PS：编程或相关学习，不会的多问AI

## 2.	计算机就业通识
➣学计算机的主要出路？
答：常见有以下出路：
•科研
•互联网
•制造业
•国企/银行/医院/军工等（电子信息岗）
•考公与选调

➣计算机对口就业方向？ 
答：除去考公/科研/国企外，一般有以下大方向：
•互联网（一般偏软）：
-前端
-后端
-算法（AI算法/业务算法）
-测试
-运维
-网络安全
-游戏
•制造业（一般偏硬）：
-半导体/芯片
-电子电器/仪器仪表（嵌入式最火。制造业大且广，就业本质是懂编程的本领域人才，不同方向差异大需具体分析）
-通信

➣选工作/方向的关键因素？
个人观点：三个不讨厌
1.	不讨厌这个行业
2.	不讨厌干这个工作时周围的人/环境
3.	不讨厌这份工作的日常/工作流/工作状态

这三个比纸面的待遇更深层，也更磨人，是决定该工作/方向能不能干长久的关键，这也是为何即便有时纸面待遇较差，我们仍会选择另一份工作。

- 求职没有那么玄乎，你提升自己的身价和实际能力，靠营销包装吹嘘好自己，把自己摆上货架，企业来挑，相中了眼缘（过了初筛和简历筛）或者朋友推了产品（内推），就开聊，聊聊你是不是正常人，看看你的成色值不值这个价钱，再想办法把你的价格压低一点，最好能多白嫖一点劳动力，少花或不花米，最后买完成交，这就是求职
- 顺着市场来，做好简历展示和技术栈的垂直度，让企业和hr觉得你很合适，很匹配，还很物超所值，但广度也别丢。包装主要靠简历和面经，简历可以找前辈帮忙优化，面试怎么说多面几次就练熟了，学长的某个朋友甚至能一边杀穿A大一边面试，还过了。。
- 是否读研根据你的方向来，有的就业方向吃研究生这个title，那就得读，有的不吃，甚至同年龄本科比研究生还吃香（因为多上三年班过来就是生产力，好用还便宜），那就别硬着头皮读。大学生活最忌讳人云亦云随大流，啥想法没有，跟个稻田里的稻子一样只顺应天象，不自觉的生长，不自觉的死亡，这很危险，大概率也就是变成真“稻子”，被收了韭菜，牺牲掉了。
- 想保研的，尽量用最少的时间刷到最高的绩点，多出来的时间去打性价比高的竞赛等，进实验室乃至拿论文需要看机缘和有没有遇到合适导师，最好是听认识的学长学姐介绍
- 春秋招是竞争最激烈的时候，一个对应暑期实习，一个对应寒假实习，日常实习比这两个招的更简单，大一想去实习可以多试试日常
