如果你想开一个自己的 Minecraft 服务器，最先需要面对的往往不是“怎么写开服脚本”（这甚至可能是最简单的一步），而是：

- 我的网络能不能让别人直接连进来？
- 我的家里宽带为什么没有公网 IP？
- 没有公网 IP，我该怎么办？
- 如何获取公网 IP？

这些问题，正是很多网络小白遇到困难的地方。

## 1. 为什么我的网络不能让别人直接连进来？

在境内，由于历史等诸多原因，绝大多数用户并不是直接拿到一条“可以对外公开的公网地址”。很多时候，家里宽带、宿舍网络、移动网络和运营商 Wi‑Fi 都是 NAT 环境。
这意味着：

- 你的电脑能访问互联网；
- 但别人并不能直接通过网络访问你的电脑；
- 服务器监听的端口，也不一定能从外网进来。

Minecraft 服务器最典型的需求就是“外部玩家能连接到我的服务器”。而这件事在 NAT 场景中，往往要靠额外方案：

- 云服务器中转；
- frp、Tailscale、Cloudflare Tunnel 等隧道方案；
- 反向代理或中间层转发。

如果你直接以为“我家里开个 Java 进程，别人就能连”，那在很多情况下，现实会让你很快失望。Minecraft 这类游戏服务器，它必须要有外部玩家能连到服务器地址和端口。
在国内，自托管的主要难点其实是“把网络入口弄通”。
## 2. 为什么没有公网 IP？

### 什么是 NAT？

NAT，全称 Network Address Translation，即“网络地址转换”。

由于全球 IPv4 地址资源有限，中国通过大规模部署 NAT 技术来缓解地址短缺，因此形成了一种与很多其他地区不同的、多层级的复杂网络环境。它的核心特点是：绝大多数普通用户无法直接获得独立的公网 IPv4 地址，而是处于一个“内网中的内网”。
具体来说，中国的网络环境形成了独特的“多层 NAT”结构，类似于一个网络“套娃”。

### NAT 是怎么工作的？

第一层：家庭/企业内网：这是最内层，也就是你家里或办公室的局域网（如192.168.x.x）。所有设备通过路由器上网，这是全球普遍采用的方式。
第二层：运营商级网络地址转换（CGNAT）：这是我国网络环境最显著的特殊之处。你的路由器获取的IP地址，往往不是真正的公网IP，而是运营商内网的一个地址（常见如100.64.0.0/10网段）。运营商会再进行一次大规模NAT，让成千上万的用户共享一个公网IP上网。这种“假公网IP”技术也被称为NAT444。
第三层：互联网：经过两层NAT转换后，流量才最终到达公共互联网。

### 为什么会有 NAT？

这种网络环境的形成，主要是由历史原因和现实挑战共同导致的：

IPv4地址严重不足：中国是全球网民最多的国家，但人均IPv4地址资源却非常匮乏（如2023年统计人均仅约0.8个）。为缓解这一矛盾，中国较早就采用了NAT技术。
历史路径依赖：由于NAT在早期有效解决了燃眉之急，这使得国内网络在向IPv6演进时缺乏足够动力，形成了一种路径依赖。

## 3.没有公网 IP，我该怎么办？

### **内网穿透**

**内网穿透**是目前最主流、适用范围最广的方案，无论你身处几层NAT之后都能工作。其原理是内网设备主动连接一个公网服务器，建立一条稳定的通信隧道。外网用户访问服务时，流量会通过这台公网服务器中转。这类服务通常价格低廉，但是缺点是稳定性欠佳。而且，每个服务器带宽有限，无法承载无限多的流量。
以下是目前常见的几款内网穿透软件：

- FRP (Fast Reverse Proxy) 高性能、开源、可自建。
  - 优点：性能强悍，支持P2P模式，功能强大且免费。
  - 缺点：需要自己购买云服务器进行部署，有一定技术门槛。
- 花生壳 (Oray)：本土化服务、软硬结合。在国内使用体验较好，对新手友好。
  - 优点：有免费版，中文界面，配置引导清晰。
  - 缺点：~~免费版带宽和流量有限~~（免费的还要啥自行车！），高级功能需付费。
- Sakura Frp（俗称“樱花”）：国内网络优化版。基于FRP，针对国内网络环境进行了优化，提供免费节点，速度相对有保障。
  - 优点：国内访问延迟较低，提供免费服务。
  - 缺点：~~免费节点稳定性和速度受用户量影响~~（免费的还要啥自行车！）。

### **组建虚拟局域网**

**组建虚拟局域网**就是利用软件在互联网上“拉”一根看不见的网线，把分布各地的设备连接起来，让它们像在同一个局域网里一样，直接、安全地互相访问。这对于没有公网IP、身处多层NAT环境下的我们来说，是解决远程访问和互联问题非常有效的方法。

常用的组建方式主要有两种：

#### 1.使用商业软件
- 蒲公英 (Oray):
  - 优点：本土化，简单易用。国内服务，延迟低；支持全平台；免费版支持5台设备；有硬件路由器方案，插电即用。
  - 缺点：~~设备数量不多，带宽限速，中继模式限速严重，高峰期不稳定~~（免费的还要啥自行车！）。
- Radmin VPN
  - 优点：完全免费，不限人数。简单直接，无需注册账号。
  - 缺点：~~服务器在海外，国内延迟高；仅支持Windows平台；不稳定~~（免费的还要啥自行车！）。
- NetPlus
  - 优点：虽然付费但是足够便宜，每天签到还送余额。（作者之前自用的）
  - 缺点：~~稳定性欠佳，端口有的时候会被挤掉，节点经常变动~~（免费的还要啥自行车！）。

#### 2.使用开源/技术型工具
这类工具提供了更高的自由度和性能，但需要一定的动手能力。
- ZeroTier:
  - 优点：P2P直连延迟可低至5-20ms；全平台支持；免费版支持25台设备；可自建Moon节点加速国内连接。
  - 缺点：~~海外中继服务器导致的高延迟和稳定性差~~（免费的还要啥自行车！）；如果追求低延迟和高稳定性需要自行搭建节点。
- Tailscale：
  - 优点：现代、强大、连接率高。基于WireGuard协议，NAT穿透能力极强；全平台支持；免费版支持设备数最多（100台）；提供MagicDNS等便捷功能。
  - 缺点：~~海外中继服务器导致的高延迟和稳定性差；控制平面闭源，无法完全自建；特定场景下有性能问题~~（免费的还要啥自行车！）。

## 4.如何获取公网IP？

**注意：以下内容为作者个人获取公网 IP的方式，不同地区获取方式不一定相同！！！**

在**很早很早之前**，有的地方（不同省，甚至不同地级市的政策都不一样）办理家庭宽带送公网 IP。但是随着 IPv4 的日渐枯竭，现在也基本不会提供公网 IPv4了。以作者所在的安徽省某地级市为例，作者所在的市办理宽带无法给与公网 IPv4。作者之前用的是移动，移动可以提供企业专线（**静态 IPv4 地址**），上下行都是百兆（100 Mbps），费用是 **300 RMB/月**（显然这个价格一般学生负担不起）
所以后来作者携号转网去了**电信**，在办理宽带的时候，和营业员说我需要**非NAT地址**这个服务。这个服务在**电信**的收费是 **50 RMB/月**。这样拿到的**动态公网 IPv4**，然后只需要做一次 DDNS （Dynamic Domain Name Server，动态域名服务）把域名和IP绑定在一起就好了。
