# 内容术语与维护规范

## 常用术语

- **标签 / tag**：文章的主题标识，一篇文章可以属于多个标签，供读者聚合浏览与检索。
- **校园服务门户 / 一网通办**：学校统一在线服务入口 ehall.ysu.edu.cn，用于进入教务、图书馆、缴费等服务。
- **校园网接入**：连接校园网并认证的过程，涵盖宿舍有线/无线、教学区 Wi-Fi、运营商宽带与校外 VPN 接入。
- **免费资源**：包括学生专属权益，以及面向大众的免费层或免费额度，介绍时应说明适用条件。
- **作者 / authors**：对文章有实质贡献的撰写、修改、补充或核实者；用于记录贡献，不作为内容分类。

## 标签与作者

每篇文章使用 1 到 3 个标签，优先复用[已有标签](/tags)，新增前检查近义名称。作者写入 frontmatter 的 `authors`，并在作者列表中登记；具体格式见[贡献指南](/CONTRIBUTING)。

## 时效性与地区适用性

- 校园政策、套餐和流程以学校当期官方通知为准；登录后页面或学生实测需注明日期。
- 免费额度、价格、模型、软件版本和学生权益应引用官方页面，标注最后核验时间。
- 海外服务除能否访问，还需核对中国大陆是否为官方支持地区，以及账号、支付、数据处理和条款限制。
- 公开网站需区分境外托管与中国大陆服务器；后者通常涉及 ICP 备案。
- 不推荐来源不明的镜像、中转站和下载站，也不将第三方服务预置项视为知识库背书。
