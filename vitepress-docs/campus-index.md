# 校园服务导航

本页汇总校园侧的入口：校园网接入与校外访问、一网通办与教务系统、正版软件与校园邮箱，以及学生社团、常用部门和校内生活信息。

> 校园政策、办事流程和系统界面会按学期调整。本页只负责指路，具体步骤、截图和注意事项在各篇文章里；办理前请以学校当期通知和登录后的页面为准。

## 按标签浏览

### 校园网与校外访问

- **[校园网简介](./campus-network-index.md)**：接入方式、能访问哪些资源，以及办理运营商校园卡前要逐项确认的条款
- **[连接与认证](./campus-network-connect.md)**：进入认证页、用统一身份认证登录，以及在自助服务里查看套餐和在线设备
- **[校园网常见问题](./campus-network-qa.md)**：连不上时按三类情况排查，附免费流量与同时在线设备数的规则
- **[学校 WebVPN（校外访问系统）](./campus-network-vpn.md)**：在校外打开部分校内系统和学校已购买的电子资源，它不是通用代理

### 一网通办与教务系统

- **[一网通办](./campus-service-index.md)**：成绩查询、费用缴纳和图书馆座位预约的入口，以及本科教务、可信数据服务平台等路径

### 正版软件与校园邮箱

- **[校园正版化](./campus-ms-index.md)**：Windows、Office、Visio、WPS、福昕 PDF、中望 CAD、MWORKS 的下载与激活
- **[校园邮箱](./campus-mail-index.md)**：在一网通办申请邮箱、登录 stumail 的步骤，以及 Microsoft 365、GitHub、JetBrains 教育计划的验证入口

### 学生组织与校内生活

- **[学生社团与组织](./campus-clubs.md)**：校内备案社团与各级学生组织名录，按类别和主管部门整理
- **[常用部门与微信公众号](./campus-departments-wechat.md)**：教务处、信息技术中心、微后勤、图书馆的职责与官方公众号
- **[舒适在校点外卖指南](./guidance-takeout.md)**：东西区取餐点位、商家推荐与注意事项（信息变化快，下单前以平台为准）
