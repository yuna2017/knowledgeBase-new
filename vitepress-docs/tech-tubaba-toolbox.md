# 图吧工具箱简介与官方下载

## 简介

图吧工具箱是图拉丁吧社区出品的免费 Windows 工具箱，把装机、验机常用的硬件检测与测试工具集中在一个界面里，按用途分类，支持一键下载和启动，适合刚装完机或准备交易二手硬件时快速检查。

常用工具大致包括：

- **硬件信息**：CPU-Z、GPU-Z、AIDA64 等，查看 CPU、显卡、内存、主板和硬盘信息
- **屏幕检测**：纯色与灰阶测试页，检查坏点、亮点和漏光
- **稳定性测试**：烤机工具，配合温度监控验证散热与稳定性
- **硬盘检测**：DiskInfo、分区与基准测试工具
- **其他分类**：清理、驱动等分类下的第三方工具

> 工具箱本身免费。内置工具多为各厂商或社区提供的免费版本，个别工具的授权和使用条款以工具自身说明为准。

1. **只从官网下载**。图吧工具箱流传广、名字知名，第三方下载站和网盘里的“重打包版”可能捆绑推广或恶意软件；官方下载入口可能调整，以官网当前页面为准。

3. 烤机、超频类测试会长时间满载运行，注意温度、供电和散热，不要无人看管长时间运行。
