# 收到了

谢谢，已经进队列了。

同类需求会合并计数，所以第 30 个提同一件事的人不是白提——那会让它更靠前。每条都会在[反馈执行状态](/wanted-status)里拿到一个状态，包括不做的那些。

能承诺的是「会被看到、会被标注」，不能承诺「一定会做」。写不过来的时候，清单会一直挂在那儿，而不是假装处理过了。
